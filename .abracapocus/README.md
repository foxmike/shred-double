# SHREDDOUBLE

## Purpose

Build ShredDouble: an algorithmic rhythm doubler that synthesizes convincing double-tracked width from a single take. C++20/JUCE plugin targeting VST3, CLAP, LV2, and Standalone. V=2 or 4 virtual voices, each fed the mono source through an independent chain of (a) bounded mean-reverting random-walk timing + pitch humanization (no LFO — stochastic and non-periodic by design), (b) per-voice decorrelation via coprime Schroeder allpass diffusion + subtle EQ tilt, and (c) the same shared-LP mono-safety crossover as ShredWidth so lows stay centered under mono fold-down. Deterministic given a seed (masterSeed stored in state; Re-roll generates a new seed on demand). Reuses ShredWidth's PitchShifter, DelayLineFrac, MonoSafetyCrossover, WidthProcessor, and GUI metering components verbatim. Full product specification in ShredDouble_Build_Spec.md. Section 16 open decisions are materialized at their defaults (D3 Rate=correlation-time / Tightness=depth-macro remap confirmed, default V=2, Studio/Live included, Width+OutTrim parity included, Re-roll as GUI button with masterSeed in state, default Mix 50%, no AU, shared files copied from ShredWidth).
